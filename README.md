# Titanic Data Pipeline using Python and SQL

## 📌 Project Overview
This project demonstrates a simple data engineering pipeline using Python and SQLite.

## ⚙️ Technologies Used
- Python
- Pandas
- SQLite

## 🚀 Steps Performed
- Loaded dataset using Pandas
- Cleaned missing values
- Created new feature (FamilySize)
- Stored processed data into SQLite database
- Performed SQL queries for analysis

## 📊 Sample Insights
- Passenger count by gender
- Survival count

## 📁 Files
- pipeline.py → main script
- titanic.csv → dataset

## 🎯 Outcome
Built an end-to-end beginner data pipeline project demonstrating ETL process.
